# 📊 Classroom Attendance Prediction System

## 📌 Project Overview

The Classroom Attendance Prediction System is a Machine Learning based application developed to predict the expected attendance percentage for an upcoming lecture.

The system uses historical attendance records and academic schedule information such as subject, day, time, faculty, lecture type, previous attendance and other relevant factors to generate an attendance prediction.

The project also provides an interactive Streamlit dashboard for prediction and historical attendance analytics.

---

## 🎯 Objectives

- Predict expected attendance percentage for an upcoming lecture.
- Analyze historical attendance patterns.
- Identify subjects with high and low attendance.
- Analyze attendance based on weekdays.
- Compare morning and afternoon attendance.
- Analyze faculty-wise attendance.
- Compare different Machine Learning models.
- Provide an easy-to-use web interface using Streamlit.

---

## 📂 Dataset

The dataset contains historical classroom attendance records.

### Dataset Information

- Total Records: **294**
- Total Features: **30**
- Target Variable: **Attendance %**

The dataset contains information related to:

- Lecture date
- Day
- Start time
- Semester
- Lecture number
- Subject
- Faculty
- Practical/Theory
- Weather
- Assignment status
- Special events
- Previous lecture attendance
- Previous 3 lecture average
- Faculty experience
- Attendance percentage
